# Turbo Happy Ghast

The Happy Ghast's default flight speed can feel rather slow. Because of this, its flight speed is significantly increased as soon as you mount it, making it much faster.

## How it works

Using the `minecraft:flying_speed` attribute introduced in snapshot [25w20a](https://www.minecraft.net/en-us/article/minecraft-snapshot-25w20a), the Happy Ghast's flight speed is increased while a player is riding it. Once the player dismounts, its speed automatically returns to the default value. This prevents the Happy Ghast from flying around too quickly on its own.
