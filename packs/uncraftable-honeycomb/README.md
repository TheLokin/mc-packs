# Uncraftable Honeycomb

A simple and lightweight quality-of-life addition that allows you to uncraft Honeycomb Blocks back into Honeycombs, making it easier to store vast amounts of Honeycomb Blocks without losing the ability to turn them back when needed.

## Crafting Recipes

This adds standard shapeless vanilla unpacking mechanics to the crafting table:

- **1x Honeycomb Block** $\rightarrow$ **4x Honeycomb**
