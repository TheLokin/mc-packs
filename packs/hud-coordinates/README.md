# HUD Coordinates

Shows your coordinates, the direction you are facing and the current in-game time in the action bar, right above the hotbar, so you can check them at any moment without opening the F3 debug screen.

## How it works

A function runs every tick to read each player's position and the current world time, displaying the information on a single action bar line. It shows the X, Y and Z coordinates, the cardinal direction (N, S, E or W) and the time in 24-hour format.
